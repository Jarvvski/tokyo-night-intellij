# Upstream attribution

The color palettes ported by this plugin originate from the Zed theme
[`ssaunderss/zed-tokyo-night`](https://github.com/ssaunderss/zed-tokyo-night),
which is distributed under the MIT License. The pinned upstream palette is
vendored verbatim at `tools/vendor/tokyo-night.json`.

The Tokyo Night color scheme was originally created by Enkia. Key-name mappings
were cross-referenced against public IntelliJ ports (for example
`junkfactory/tokydark-jetbrains` and exported community color schemes); only key
identifiers were consulted, never their color values.
