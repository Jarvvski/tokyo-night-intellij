# Sample project

Throwaway sources used to capture Tokyo Night screenshots. Open this folder as a
project in a sandbox IDE and pick a theme under Settings > Appearance.

- `src/main/kotlin` - Kotlin roles (KDoc, annotations, string interpolation)
- `src/main/java` - Java roles (Javadoc, text block, lambda)
- `src/main/python` - Python roles (decorator, docstring, f-string)
- `src/main/typescript` - TypeScript roles (union types, generics, template literal)
- `config` - JSON and YAML
- `sql` - SQL
- `scripts/ansi-demo.sh` - prints ANSI colours for terminal screenshots

None of it is meant to compile or run as a real project.
